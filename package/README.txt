PPM 1.0.0
(Ppm is Progress Manager)

[English]

PPM is a Windows application for managing the progress of animation production.

To start PPM, double-click ppm.exe in this folder.
If you want to try it first, follow the tutorial in the manual. It uses the sample project in the stuff folder.

Manual
  The manual for this version (1.0.0) is on GitHub:
  https://github.com/opentoonz/ppm/tree/v1.0.0/docs

  - Manual (English):  https://github.com/opentoonz/ppm/blob/v1.0.0/docs/index.md
  - Installation:      https://github.com/opentoonz/ppm/blob/v1.0.0/docs/getting-started/installation.md
  - Tutorial:          https://github.com/opentoonz/ppm/blob/v1.0.0/docs/getting-started/tutorial.md

[日本語]

PPM は、アニメーション制作の進捗を管理するための Windows 用ソフトウェアです。

このフォルダにある ppm.exe をダブルクリックすると起動します。
まず試してみたいときは、マニュアルのチュートリアルをご覧ください。stuff フォルダにあるサンプルのプロジェクトを使います。
