# UI の言語と翻訳ファイル

PPM の画面は、英語で作られています。
ほかの言語で表示するときは、その言語の**翻訳ファイル**を使います。
PPM には、日本語の翻訳ファイル `PPM_ja.qm` が付いています。

## 画面の言語を選ぶ

画面の言語は、各スタッフが **環境設定** の **言語** で選びます（[初回設定](../getting-started/initial-setup.ja.md) を参照）。

- 変更は、PPM を次に起動したときに反映されます。
- 「English」を選ぶと、翻訳を使わずに英語で表示します。
- 一度も選んでいない場合は、Windows の表示言語に合わせます。その言語の翻訳ファイルが無いときは、英語で表示します。
- スタジオ全体の初期値は、Stuff フォルダの `defaultusersettings.ini` の `LanguageCode` で決められます（[Stuff フォルダ](stuff-folder.ja.md) を参照）。

## 翻訳ファイルの置き場所

翻訳ファイルは、Stuff フォルダの `loc` フォルダに、`PPM_言語コード.qm` という名前で置きます。

```
stuff/
└─ loc/
   ├─ PPM_ja.qm      … 日本語
   └─ PPM_fr.qm      … フランス語（追加した場合の例）
```

- 環境設定の **言語** には、「English」と、`loc` フォルダにある翻訳ファイルの言語が並びます。言語の名前は、その言語自身の書き方で表示されます（例：`fr` なら「français」）。
- 選んでいる言語の翻訳ファイルが見つからないときは、起動時に警告が表示され、英語で起動します。このとき、環境設定の **言語** には、言語の名前の後ろに「(translation file not found)」と表示されます。
- Stuff フォルダを共有している場合は、`loc` フォルダに翻訳ファイルを置けば、全員が選べるようになります。

## 言語によって変わるもの

| 内容 | 言語 |
|---|---|
| ボタン、メニュー、メッセージなど、PPM の画面 | 各スタッフが選んだ言語 |
| カットのログの見出し、日時の書き方、`[失敗]` などの文字 | **操作した人** の PPM の言語（[バックアップと復旧](backup.ja.md) の「ログから経緯をたどる」を参照） |
| リネームスクリプトのルールの名前と説明 | スクリプトに、その言語の名前があればその言語（[リネームスクリプト](../integrations/rename-scripts.ja.md) を参照） |
| 工程グループ、工程、アクション、カット情報の名前、Chat のメッセージなど | 翻訳されません。プロジェクトの設計者が書いたとおりに表示されます |

サンプルプロジェクトの工程の名前などは、日本語で書かれています。

## 言語を追加する

新しい言語の翻訳ファイルを作るには、Qt 6 の翻訳ツール（Qt Linguist、`lupdate`、`lrelease`）を使います。
これらは Qt のインストールに含まれています。

翻訳のもとになるファイル（`.ts`）は、ソースコードの `sources/translations` フォルダにあります。
PPM の画面に表示される `.qm` ファイルは、この `.ts` ファイルから作ります。

### ビルド環境がある場合

1. `sources/CMakeLists.txt` の次の行に、追加する言語の言語コードを足します。

   ```cmake
   set(LANGUAGES ja fr)
   ```

2. CMake のターゲット `translation_PPM` をビルドします。
   `sources/translations/PPM_fr.ts` が作られ、`stuff/loc/PPM_fr.qm` が書き出されます。
3. `PPM_fr.ts` を Qt Linguist で開いて翻訳し、保存します。
4. もう一度 `translation_PPM` をビルドすると、翻訳した内容で `PPM_fr.qm` が書き出されます。

### ツールだけを使う場合

ソースコードのフォルダで、次のように実行します。

```bash
lupdate sources -ts sources/translations/PPM_fr.ts
```

作られた `PPM_fr.ts` を Qt Linguist で翻訳して保存したら、`.qm` ファイルを書き出します。

```bash
lrelease sources/translations/PPM_fr.ts -qm stuff/loc/PPM_fr.qm
```

### 翻訳ファイルを使う

1. できた `PPM_fr.qm` を、Stuff フォルダの `loc` フォルダに置きます。
2. 環境設定の **言語** で、追加した言語を選びます。
3. PPM を起動し直します。

### PPM を新しくしたとき

PPM が新しくなると、翻訳されていない文が増えることがあります。
上と同じ手順で `.ts` ファイルを更新すると、新しい文が「未完了」として追加されるので、それを翻訳して `.qm` ファイルを書き出し直します。
翻訳されていない文は、英語のまま表示されます。

作った翻訳を PPM に取り込んでほしい場合は、[開発に参加する](../about/contributing.ja.md) を参照してください。
