# リテイク

工程を一通り終えたカットに修正作業を出すことを、**リテイク**と呼びます。
リテイクを出すと、カットのテイク番号が1つ増え、リテイク用の工程グループに移ります。
仕組みは [カットが工程を流れる仕組み](../concepts/scene-flow.ja.md) で説明しています。

工程グループの中でカットを前の工程に戻す**工程内リテイク**は、カットの一覧の行から出します（[カットに対する操作](scene-operations.ja.md) を参照）。

## リテイクを出す

1. 上部の **リテイク** ボタンを押します。**新規リテイクを発行** の画面が開きます。
2. 一番上の欄に、リテイクを出すカット名を入れます。カンマ（`,`）、コロン（`:`）、セミコロン（`;`）で区切って、複数のカットをまとめて入れられます。
3. **テイク番号** を決めます（下の「テイク番号」を参照）。
4. **リテイク先** で、カットを送る工程グループのボタンを押します。
5. **コメント** に、リテイクの内容を書きます。
6. **リテイクを出す** を押します。

<!-- 画像：images/ja/using/retake-dialog.png（新規リテイクを発行の画面。カット名、テイク番号、リテイク先のボタン、コメントが見えている状態） -->

「リテイクが発行されました。」と表示されたら、完了です。
**カットフォルダを開く** を押すと、新しく作られたカットフォルダを開きます。
画面は開いたまま入力欄が空になるので、続けて別のリテイクを出せます。終わったら **閉じる** を押します。

カットフォルダやキューファイルを作れなかったカット、カット情報のファイルに書き込めなかったカットがあると、カット名と理由が表示されます。
カットフォルダを作れなかったときと、カット情報に書き込めなかったときは、そのカットにはリテイクが出されません。キューファイルだけを作れなかったときは、リテイクは出されるので、キューファイルを手で置いてください。

### リテイクを出せるカット

リテイクを出せるのは、プロジェクト設定で「リテイク発行元」をオンにした工程グループに所属しているカットです。
サンプルのプロジェクトでは、撮影の工程グループがリテイク発行元です。撮影まで進んだカットに、リテイクを出せます。

条件に合わないカットが入っていると、テイク番号の横に赤字で、理由ごとにカット名が表示され、**リテイクを出す** ボタンが押せなくなります。理由は次のとおりです。

- リテイク発行元の工程グループにいない（発行元の工程グループの名前も表示されます）
- カット情報を読み込めなかった
- テイク番号が今のテイク以下（**手動** のとき。今のテイク番号も表示されます）

プロジェクトに、リテイク発行元の工程グループや、リテイク用の工程グループがない場合も、そのことが赤字で表示され、リテイクを出せません。

### リテイク先

**リテイク先** には、プロジェクト設定で「リテイク」をオンにした工程グループが、ボタンで並びます（サンプルでは「原画リテイク」「動画リテイク」「仕上リテイク」）。
はじめは、左端のボタンが選ばれています。

## テイク番号

**テイク番号** では、新しいテイク番号の決め方を選びます。

- **自動**：カットごとに、今のテイク番号に1を足した番号にします。はじめてリテイクを出すカットは、テイク2になります。
- **手動**：右の欄に入れた番号にします。PPM を通さずにテイク番号が進んだカットに、番号を合わせたいときに使います。今のテイク番号より大きい番号を入れてください。

テイク番号の横には、どのカットが何テイクになるかが青字で表示されます（例：`0001, 0002 -> テイク 2  |  0003 -> テイク 3`）。

カットの今のテイク番号は、**カット検索** の「テイク」で確かめられます（[メイン画面](main-window.ja.md) を参照）。

## リテイクを出した後

リテイクを出すと、次のことが行われます。

1. カット情報のファイルに、新しいテイク番号、リテイク先、コメント、日時が記録されます。
2. リテイク先の工程グループに、テイク番号の付いたカットフォルダ（例：`c0001_t02`）が作られ、その中に `retake_start.txt` が置かれます。
3. カットの所属が、リテイク先の工程グループに移ります。ログには「リテイク出し（テイク 2へ）」のように記録されます。
4. プロジェクトにカット情報 `RETAKE_WIP` があれば、リテイク先の工程グループの名前を値にして付けられます（例：「リテイク作業中:原画リテイク」）。外し方は、[カット情報（プロジェクト設定）](../designing/info-tags.ja.md) の「PPM の機能が使うカット情報」を参照してください。

リテイクを出し終わると、リテイク先（と、カットが元いた工程グループ）について、工程グループの更新ボタンと同じ処理が自動で行われます。
`retake_start.txt` などのキューファイルが探され、当てはまる工程にカットが並びます。
どの工程に並ぶかは、プロジェクトの設計によって決まります。

リテイク用の工程グループの一覧では、カット名にテイク番号が付いて表示されます（例：`0001_t02`）。
