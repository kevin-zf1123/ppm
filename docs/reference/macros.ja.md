# マクロ一覧

**マクロ**は、`[CUTNUMBER]` のように角かっこで囲んだ文字列で、PPM が使うときに、カットごとの値に置き換えられます。
PPM にもともとある**組み込みのマクロ**と、プロジェクトの設計者が作る**パスマクロ**があります。

## 組み込みのマクロ

### パスに使うマクロ

パスマクロのパス、工程の条件パス、ステップのパス、カットサムネイルのパスなどで使えます。

| マクロ | 置き換えられるもの | 例 |
|---|---|---|
| `[ROOT]` | プロジェクトのルートフォルダ（[基本情報](../designing/basics.ja.md) を参照） | `//fileserver/anime/my_title` |
| `[PREFIX]` | カット番号の接頭辞 | `c` |
| `[CUTNUMBER]` | カット番号 | `0012`、`0034a`、`0056_0078`（兼用カット） |
| `[SEQUENCE]` | シークエンス。カット番号の先頭の数字から、下2桁を除いたもの。「100カットごとにまとめる [SEQUENCE]」がオフのときは空になります。 | `00`（カット `0012`）、`01`（カット `0123a`） |
| `[EPISODE]` | 話数の名前（「話数あり」のとき） | `01` |
| `[USER_NAME]` | 環境設定のユーザー名（空のときは Windows のユーザー名） | `peter` |
| `[TAKE]` | テイクの印。テイク1は空、テイク2から `_t02`、`_t03`… | `_t02` |
| `[TAKE-1]` | 1つ前のテイクの印。テイク1のときは空、テイク2のときは `_t01`、テイク3から `_t02`、`_t03`…。リテイクを出すとき、前のテイクの素材を切り分けるサブフォルダの名前に使います | `_t02`（テイク3） |
| `[PREV_EXISTING_TAKE]` | 今のテイクより前で、実際にフォルダがある、いちばん新しいテイクの印。見つからないときは空 | `_t02` |
| `[R_TAKE]` | 撮影用のテイクの印。テイク1は空、テイク2は `_r`、テイク3から `_r02`、`_r03`… | `_r` |
| `[R]` | 工程内リテイク中の印。工程内リテイク中（カット情報 `REWIND` が付いている間）は `_r`、それ以外は空 | `_r` |

- `[SEQUENCE]` が空になったときに、パスに `//` が残らないよう、余分な区切りは取り除かれます。
- 兼用カット（`0010_0011` など）では、フォルダの部分の `[CUTNUMBER]` は兼用のカット番号（`0010_0011`）に、ファイル名の部分の `[CUTNUMBER]` は個々のカット番号に置き換えられます。

#### 前のテイクを指すマクロ（`[TAKE-1]` と `[PREV_EXISTING_TAKE]`）

リテイクを出したときに、前のテイクのデータをコピーするステップでは、`[TAKE-1]` と `[PREV_EXISTING_TAKE]` を使い分けます。

- **`[TAKE-1]`**：今のテイク番号から1を引いた番号の印です。フォルダがあるかどうかは調べません。
  `[TAKE]` と違い、テイク2のときも空にならず `_t01` になります。
  前のテイクのデータを、新しいテイクのカットフォルダの中のサブフォルダ（`_t01`、`_t02`…）に切り分けて、参考用やバックアップとして残すときの、サブフォルダの名前に使います。
- **`[PREV_EXISTING_TAKE]`**：今のテイクより前のテイクを新しい順にさかのぼり、パスのフォルダが実際にあるいちばん新しいテイクの印です。
  前のテイクの番号から順にテイク2まで調べ、どれも見つからないときは空（テイク1のフォルダ）になります。
  リテイクを、テイクごとに違う工程グループに出したときでも、いちばん新しいデータがあるフォルダからコピーできます。
  フォルダの有無を調べるので、フォルダのパスに使います（ファイルのパスでは見つかりません）。

たとえばサンプルプロジェクトの「原画リテイク受付」では、「フォルダ内容をコピー」ステップで、`[GENGA_PREV_EXISTING_TAKE_CUTFOLDER]`（パスに `[PREV_EXISTING_TAKE]` を含むパスマクロ）から `[GENGA_RETAKE_CUTFOLDER]/[TAKE-1]` へコピーしています。

| 状況 | `[GENGA_PREV_EXISTING_TAKE_CUTFOLDER]`（コピー元） | `[GENGA_RETAKE_CUTFOLDER]/[TAKE-1]`（コピー先） |
|---|---|---|
| テイク2の原画リテイク | `c0001/genga` | `c0001_t02/genga/_t01` |
| テイク3の原画リテイク（テイク2も原画リテイク） | `c0001_t02/genga` | `c0001_t03/genga/_t02` |
| テイク3の原画リテイク（テイク2は動画リテイクで、`c0001_t02/genga` が無い） | `c0001/genga` | `c0001_t03/genga/_t02` |

#### 工程の条件パスでのテイクのマクロ

工程の条件パスでは、テイクのマクロのうち、工程グループの **テイク表記** で選んだものだけが置き換えられます（[工程グループ](../designing/workflow-groups.ja.md) の「テイク表記」を参照）。

| テイク表記 | 条件パスで置き換えられるマクロ |
|---|---|
| なし | なし |
| 工程内リテイク [R] | `[R]` |
| テイク番号 [TAKE] | `[TAKE]` |
| 撮影用テイク番号 [R_TAKE] | `[R_TAKE]` |

ステップのパスでは、すべてのテイクのマクロが置き換えられます。

### 特定の場所だけで使えるマクロ

| マクロ | 使える場所 | 置き換えられるもの |
|---|---|---|
| `[CURRENT_DATE]` | **フォルダ内容をコピー** のコピー先のパス、**空フォルダの作成** のフォルダパス | 実行した日付（`261030` の形） |
| `[CURRENT_DATE]` | **Googleスプレッドシートに入力** の値、**Google Chatに通知を送る** のメッセージ | 実行した日付（`2026/10/30` の形） |
| `[USER_NAME]` | **Googleスプレッドシートに入力** の値 | 環境設定のユーザー名 |
| `[EPISODE]` | **Googleスプレッドシートに入力** のシート名 | 話数の名前 |
| `[CURRENT_DATETIME]`、`[PROJECT_NAME]`、`[WORKFLOW_NAME]`、`[ACTION_NAME]` | **Google Chatに通知を送る** のメッセージ、キャンセルメッセージ | 実行した日時、プロジェクト名、工程名、アクション名（[Google Chat 通知](../integrations/google-chat.ja.md) を参照） |
| `[GENGA_OR_DOUGA]` | 工程グループの **XDTSファイル名** | `douga` と `genga` のうち、ファイルがある方（[工程グループ](../designing/workflow-groups.ja.md) を参照） |
| `[SKIP_CUE_FILE]` | **フォルダ内容をコピー** のコピー元のパス（これだけを書く） | キューファイルのあるフォルダ。キューファイル自体はコピーしません（[ステップ一覧](steps.ja.md) を参照） |

## パスマクロ

**パスマクロ**は、よく使うフォルダの場所に名前を付けたものです（例：`[LO_CUTFOLDER]`）。
プロジェクト設定の **パスマクロ** で作ります（[パスマクロ](../designing/path-macros.ja.md) を参照）。

- パスマクロのパスには、組み込みのマクロを使えます（例：`[ROOT]/01_LO_genga/[SEQUENCE]/[PREFIX][CUTNUMBER]/LO`）。
- 1つのパスの中で使えるパスマクロは、1つだけです。
- パスマクロのパスの中に、別のパスマクロは書けません。
- **難読化** したパスマクロは、画面には表示されず、実際にファイルを操作する直前にだけ、本当のパスに置き換えられます。

サンプルプロジェクトのパスマクロは、次のとおりです。

| マクロ | パス |
|---|---|
| `[LO_CUTFOLDER]` | `[ROOT]/01_LO_genga/[SEQUENCE]/[PREFIX][CUTNUMBER]/LO` |
| `[GENGA_CUTFOLDER]` | `[ROOT]/01_LO_genga/[SEQUENCE]/[PREFIX][CUTNUMBER]/genga` |
| `[DOUGA_CUTFOLDER]` | `[ROOT]/02_douga/[SEQUENCE]/[PREFIX][CUTNUMBER]` |
| `[COLOR_CUTFOLDER]` | `[ROOT]/03_color/[SEQUENCE]/[PREFIX][CUTNUMBER]` |
| `[SHIAGE_CUTFOLDER]` | `[ROOT]/04_shiage/[SEQUENCE]/[PREFIX][CUTNUMBER]` |
| `[SATSUEI_CUTFOLDER]` | `[ROOT]/05_satsuei/[SEQUENCE]/[PREFIX][CUTNUMBER]` |
| `[GENGA_RETAKE_CUTFOLDER]` | `[ROOT]/01_LO_genga/[SEQUENCE]/[PREFIX][CUTNUMBER][TAKE]/genga` |
| `[DOUGA_RETAKE_CUTFOLDER]` | `[ROOT]/02_douga/[SEQUENCE]/[PREFIX][CUTNUMBER][TAKE]` |
| `[SHIAGE_RETAKE_CUTFOLDER]` | `[ROOT]/04_shiage/[SEQUENCE]/[PREFIX][CUTNUMBER][TAKE]` |
