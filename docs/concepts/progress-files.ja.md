# 進捗はファイルで管理される

PPM には、進捗を記録する専用のサーバーやデータベースがありません。
進捗は、共有フォルダにある次のファイルで表されます。

| 何を表すか | どのファイルか | 置き場所 |
|---|---|---|
| カットがどの工程にいるか | キューファイル（カットの作業ファイルや目印のファイル） | 各カットのカットフォルダ |
| カットがどの工程グループに所属しているか | 工程グループごとのカットの一覧 | プロジェクト情報フォルダ |
| カットに付いている印、テイク | カットごとのカット情報のファイル | プロジェクト情報フォルダ |
| 誰が、いつ、何をしたか | カットごとのログ | ログフォルダ |

PPM は起動中、これらのファイルを読んで一覧を作り、アクションを実行するとこれらのファイルを書き換えます。
複数の PC で PPM を使っても、全員が同じ共有フォルダのファイルを見ているので、同じ進捗が表示されます。

## キューファイル

カットがどの工程にいるかは、**キューファイル**があるかどうかで決まります。
PPM は、工程の**条件パス**（[用語集](glossary.ja.md) を参照）に当てはまるファイルを、カットごとに探します。

たとえばサンプルプロジェクトでは、カット `c0001` の LO のカットフォルダに、

- `c0001_LO_ej_s_k_e.clip` があれば、LO 演出チェック
- `c0001_LO_ej_s_k.clip` があれば、LO 監督チェック
- `c0001_LO.clip` があれば、LO上がり

にいる、とみなされます。
そのため、PPM の画面を見なくても、エクスプローラーでファイル名を見れば進捗がわかります。

ただし、キューファイルが探されるのは、カットが**所属している工程グループの工程だけ**です。
LO に所属しているカットのフォルダに原画のファイルが置かれても、そのカットは原画の工程には並びません。
カットが一覧に並ぶ条件は、[カットがリストに並ぶ条件](../using/scene-list.ja.md) で詳しく説明します。

## 工程グループの所属と、工程ごとのカットの一覧

カットがどの工程グループに所属しているかは、プロジェクト情報フォルダの `progress` フォルダにある、工程グループごとのファイル（`LO.ini`、`genga.ini` など）に記録されています。
カットを登録したときや、「原画に移動」のような工程グループを移すアクションを実行したときに書き換わります。

また PPM は、工程ごとにどのカットがいるかの一覧を、検索を速くするためのキャッシュとして、プロジェクト情報フォルダの `progress_cache` フォルダに保存しています。
一覧を表示するときは、この一覧に載っているカットについてキューファイルを確かめます。
すべてのカットのすべての工程についてファイルを探すと時間がかかるため、このような仕組みになっています。

この一覧は、アクションを実行したときに更新されます。
また、メイン画面の工程グループの名前の横にある更新ボタン（回転矢印のアイコン）を押すと、その工程グループのカットのファイルを探し直して、一覧を作り直します。
ファイルを手作業で動かしたときは、このボタンを押してください（[ファイルを直接扱う](working-with-files.ja.md) を参照）。

## カット情報

カットに付いている印（[カット情報](glossary.ja.md)）と、テイクの記録は、カットごとの設定ファイルに保存されます。
ファイルの名前は、`c0001.ini` のように、接頭辞とカット番号です。

## ログ

カットに対して行った操作は、カットごとのログファイルに追記されます。
ファイルの名前は `c0001.md` のように、接頭辞とカット番号に拡張子 `.md` を付けたものです。

```
## カット c0001 のログ

|日時|Workflow|アクション|ユーザ名|
|-------------|----------|----------|---------|
|2026年 10月27日  17時34分31秒|LO 演出チェック|承認して監督に回す|peter|
```

ログには、日時、工程、実行したアクション、Windows のユーザー名が記録されます。
ログは Markdown の表の形式なので、テキストエディターでもそのまま読めます。
PPM の一覧の **ログを見る** ボタンからも表示できます。

## ファイルの保存場所

PPM が使うフォルダは、プロジェクト設定で次の3つを指定します。

| フォルダ | 内容 |
|---|---|
| ルートフォルダ（`[ROOT]`） | カットのファイルを置くフォルダ。カットフォルダは、この中にパスマクロで決めた場所に作られます |
| プロジェクト情報フォルダ | 工程グループの所属、工程ごとのカットの一覧、カット情報 |
| ログフォルダ | カットごとのログ |

サンプルプロジェクトでは、それぞれ Stuff フォルダの中の `sample_data`、`sample_data/PPM/info`、`sample_data/PPM/log` です。
プロジェクト情報フォルダとログフォルダの中は、次のような構成になります。

```
PPM/
├─ info/                      … プロジェクト情報フォルダ
│  ├─ progress/               … 工程グループの所属
│  │  ├─ LO.ini               … 工程グループ「LO」に所属するカットの一覧
│  │  └─ genga.ini            … 工程グループ「原画」に所属するカットの一覧
│  ├─ progress_cache/         … 工程ごとのカットの一覧（更新ボタンで作り直せるキャッシュ）
│  │  ├─ LO_details.ini
│  │  └─ genga_details.ini
│  └─ scene_info/             … カット情報
│     └─ 00/                  … シークエンスごとのフォルダ
│        └─ c0001.ini
└─ log/                       … ログフォルダ
   └─ 00/                     … シークエンスごとのフォルダ
      └─ c0001.md
```

- **シークエンス**を使うプロジェクトでは、カット情報とログは、シークエンスごとのフォルダ（`00`、`01`…）に分けて置かれます。使わないプロジェクトでは、`scene_info` やログフォルダの直下に置かれます。
- **話数**を使うプロジェクトでは、プロジェクト情報フォルダとログフォルダの中に話数ごとのフォルダが作られ、その中が上の構成になります。

これらのフォルダはすべて、共有フォルダに置いて、PPM を使う全員が読み書きできるようにしてください。
詳しくは [共有フォルダでの運用](../administration/shared-operation.ja.md) を参照してください。
