# ファイルを直接扱う

PPM は、中央に置いたデータベースではなく、カットごとのファイルで進捗を管理しています（[進捗はファイルで管理される](progress-files.ja.md) を参照）。
これは、PPM を通さずにファイルを手で置いたり、名前を変えたりして、進捗を直せるようにするためです。

制作の現場では、決めた流れどおりに進まないことがよくあります。
途中の工程からカットを乗せたい、手違いで進んでしまったカットを戻したい、制作の途中で工程が増えた、といった場合です。
PPM は進捗を完璧に管理することではなく、作品を完成させることを目的にしています。
そのため、このような場当たり的な直し方も、ファイルの操作で受け止められるようにしています。

ただし、手でファイルを扱う前に、PPM がどのファイルを見て進捗を判断しているかを理解しておいてください。
仕組みを知らずに操作すると、カットが一覧から消えたり、思わぬ工程に並んだりします。
このページでは、ファイルを直接扱うときに何が起きるかと、そのときの手順を説明します。

## キューファイルを手で動かす

カットがどの工程にいるかは、キューファイル（工程の目印になるファイル）があるかどうかで決まります。
そのため、キューファイルを置いたり、名前を変えたりすれば、カットを別の工程に移せます。

たとえば、次のような直し方ができます。

- **途中の工程からカットを乗せる**：その工程の条件パスに合う名前で、ファイルをカットフォルダに置きます。
- **進捗を戻す・進める**：キューファイルを、移したい工程の条件パスに合う名前にリネームします。
- **制作の途中でチェックの工程が増えた**：すでに進行中のカットのキューファイルに、新しい工程の接尾辞を付けてリネームします。

手でファイルを動かすときは、次の点に注意してください。

- **キューファイルが探されるのは、カットが所属している工程グループの工程だけです。**
  原画のファイルを置いても、カットが LO に所属したままなら、原画の工程には並びません。
  工程グループを移したいときは、[カット登録](../using/registering-scenes.ja.md) で所属を変えてください。
- **名前が条件パスに合わないと、カットはどこにも並びません。** 接頭辞や接尾辞、拡張子の綴りを確かめてください。
- **キューファイルが複数あると、カットは複数の工程に同時に並びます。** 意図したものでなければ、不要なほうを消すか、名前を変えてください。
- **アクションの直後の間違いは、取り消すのが簡単です。** アクションを実行した直後なら、ファイルを手で戻すより、灰色になった行の **取り消す** ボタンを使うほうが確実です（[カットが工程を流れる仕組み](scene-flow.ja.md) を参照）。

### 手で動かした後は、工程グループの更新ボタンを押す

PPM は、工程ごとのカットの一覧を記録しておき、一覧を表示するときはその記録に載っているカットのファイルだけを調べます。
そのため、ファイルを手で動かしただけでは、新しい工程にカットが並ばないことがあります。

ファイルを動かした後は、メイン画面で、カットが所属している工程グループの名前の横にある更新ボタン（回転矢印のアイコン）を押してください。
PPM がその工程グループのファイルを探し直し、工程ごとのカットの一覧を作り直します。

## 情報ファイルやログを直接編集する

プロジェクト情報フォルダ（工程グループの所属、工程ごとのカットの一覧、カット情報）とログフォルダの中のファイルは、テキストファイルです。
テキストエディターで開いて、直接直すこともできます。
ただし、次のことを知っておいてください。

- 工程グループの所属のファイル（`LO.ini` など）を書き換えると、カットの所属が変わります。所属を変えたいときは、[カット登録](../using/registering-scenes.ja.md) を使うほうが簡単で、間違いがありません。
- 工程ごとのカットの一覧（`progress_cache` フォルダの中）は、工程グループの更新ボタンを押せば作り直されます。手で直す必要はありません。
- カット情報のファイル（`scene_info` フォルダの中）を書き換えると、テイク番号や印が変わります。テイク番号が変わると、PPM が探すカットフォルダも変わります。印の付け外しは、**カット登録** の画面から行えます（[カット情報](../using/scene-info.ja.md) を参照）。
- ログは作業の記録です。書き換えたり消したりすると、誰がいつ何をしたかが分からなくなります。

直接編集するときは、先にファイルのコピーを取っておくと安心です。

## 開いているファイルに対してアクションを実行しない

作業用のアプリでファイルを開いたままアクションを実行すると、リネームや移動が失敗することがあります。
ファイルを保存して閉じてから、アクションを実行してください。
途中で失敗したときの対処は、[カットが工程を流れる仕組み](scene-flow.ja.md) を参照してください。

## 制作の途中でプロジェクト設定を変える

制作が始まった後にプロジェクト設定を変えると、すでにあるファイルと設定が合わなくなることがあります。
たとえば、次のような変更です。

- 条件パスのファイル名の決まりを変える：古い決まりの名前のファイルを持つカットが、どの工程にも並ばなくなります。
- パスマクロやルートフォルダを変える：PPM がカットフォルダを見つけられなくなります。
- 工程や工程グループを削除する：その工程にいたカットが、一覧に表示されなくなります。

このような場合は、すでにあるファイルを新しい設定に合うように手で直し、工程グループの更新ボタンを押します。
プロジェクト設定はスタジオ全員が使う設定なので、変更は、プロジェクトの設計者が影響を確かめてから行ってください。
詳しくは [運用中に設計を変えるときの注意](../designing/changing-in-production.ja.md) を参照してください。
