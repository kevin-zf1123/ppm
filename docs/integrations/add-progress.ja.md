# 条件付きで次工程を追加する

アクションの **次の工程** は、通常はいつも同じです。
カット情報やファイルの有無によって、**一部のカットだけ別の工程にも回したい**ときは、条件分岐のステップと **次工程の追加** のステップを組み合わせます。

## 次工程の追加ステップ

**次工程の追加** は、アクションの次の工程に、指定した工程を追加するステップです。
設定は、追加する **工程** を選ぶだけです。

- アクションを実行すると、カットは「次の工程」に加えて、このステップで指定した工程にも進みます。
- 確認画面には、「このカットは、工程「〇〇」にも送られます。」と表示されます。
- 取り消すと、追加した工程からもカットが外れます。

このステップは、条件分岐のステップ（**条件分岐：カット情報**、**条件分岐：ファイル**）の「真の場合」か「偽の場合」に入れて使います。
条件を満たすときだけ、工程が追加されます。

プロジェクト設定では、このステップで追加される工程は、アクションの **次の工程** の一覧に「[次工程の追加ステップで追加]」と表示されます。
フローチャート表示では、つながりの矢印で表示されます。

### 知っておくこと

- **条件は、確認画面を開いたときに判断されます。** 確認画面を開いた後でカット情報やファイルを変えても、そのアクションには反映されません。
- **工程を追加しただけでは、カットはその工程に並びません。** 追加した工程の条件パスに当てはまるファイル（キューファイル）も、ステップで作っておきます。
- **条件分岐に入れられるステップは1つです。** 工程の追加とキューファイルの作成のように、条件を満たすときに2つ以上のことをしたい場合は、同じ条件の条件分岐のステップを、必要な数だけ並べます。
- **ほかの工程グループの工程を追加する場合：** カットは、所属している工程グループの工程でだけ探されます（[進捗はファイルで管理される](../concepts/progress-files.ja.md) を参照）。ほかの工程グループの工程にも並べたいときは、次工程の追加と同時に傍流工程を始めるステップも追加してください（[カットが工程を流れる仕組み](../concepts/scene-flow.ja.md) を参照）。

## 使用例

### カット情報で工程を追加する

LO の演助チェックで、「BG Only」が付いているカットだけ、LO上がりに加えて「BG 原図確認」の工程にも回す例です。
「BG 原図確認」は、LO の工程グループに作っておき、条件パスを `[LO_CUTFOLDER]/[PREFIX][CUTNUMBER]_bg_check.txt` にします。

「LO 演助チェック」のアクション「承認（LO上がり）」のステップを、次のようにします。

| 順 | ステップ | 設定 |
|---|---|---|
| 1 | キューファイルをリネーム | `[LO_CUTFOLDER]/[PREFIX][CUTNUMBER][R]_LO.clip`（いつもどおり LO上がりへ） |
| 2 | 条件分岐：カット情報 | カット情報名：`BG_ONLY`、条件となる値：`1`、真の場合：**次工程の追加**（工程：BG 原図確認） |
| 3 | 条件分岐：カット情報 | カット情報名：`BG_ONLY`、条件となる値：`1`、真の場合：**キューファイルを作成**（`[LO_CUTFOLDER]/[PREFIX][CUTNUMBER]_bg_check.txt`） |

「BG Only」が付いているカットは、LO上がりと BG 原図確認の両方に並びます。
付いていないカットは、いつもどおり LO上がりだけに並びます。

### ファイルの有無で工程を追加する

カットフォルダに、特定のファイルがあるときだけ工程を追加することもできます。
たとえば、原画の演出チェックで、修正指示のファイル（`[GENGA_CUTFOLDER]/[PREFIX][CUTNUMBER]_shusei.txt`）があるカットだけ、「修正確認」の工程にも回す、といった使い方です。

この場合は、**条件分岐：ファイル** を使い、**条件となるパス** に修正指示のファイルのパスを、**存在した場合** に **次工程の追加** を入れます。
「修正確認」の工程の条件パスを、修正指示のファイルそのものにしておけば、キューファイルを作るステップは要りません。

### 次の工程を取り消す

反対に、条件を満たすときに、次の工程に**進ませない**こともできます。
条件分岐の中に **進捗の解除** を入れ、アクションの次の工程を指定すると、条件を満たすカットは、その工程に進みません。
次の工程のキューファイルを作るステップは、同じ条件の条件分岐の「偽の場合」に入れて、条件を満たさないときだけ作るようにします。
