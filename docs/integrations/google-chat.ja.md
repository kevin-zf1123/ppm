# Google Chat 通知

アクションを実行したときに、Google Chat のスペースに通知を送れます。
たとえば「原画上がり」になったら、動画の担当者がいるスペースに知らせる、といった使い方です。

通知は、Google Apps Script（GAS）のウェブアプリを経由して送ります。
スペースの Webhook の URL は PPM には保存せず、スクリプトの側に保存します。
そのため、PPM を使うスタッフには、Webhook の URL は見えません。

> Google の画面の名前や配置は、変わることがあります。見当たらないときは、Google のヘルプも参照してください。

## Chat スペースで webhook を作成する

通知を送りたいスペースごとに、Webhook を作ります。

1. Google Chat で、通知を送りたいスペースを開きます。
2. スペースの名前をクリックし、**アプリと統合** を選びます。
3. **Webhook を追加** を選び、名前（例：`PPM`）を入れて保存します。
4. 作られた Webhook の URL をコピーします。

Webhook は、Google Workspace のアカウントで使えます。
組織の設定で Webhook が使えない場合は、Google Workspace の管理者に相談してください。

## Google Apps Script を用意する

スクリプトは、Google スプレッドシート連携と同じ `google_apps_script/Code.gs` を使います。

- **スプレッドシート連携も使う場合**：[Google スプレッドシート連携](google-spreadsheet.ja.md) で作ったスクリプトに、そのまま Chat の設定を追加します。
- **Chat 通知だけを使う場合**：[script.google.com](https://script.google.com/) で **新しいプロジェクト** を作り、`Code.gs` の内容を貼り付けて保存します。

### 投稿先を登録する

1. Apps Script のエディタで、左の **プロジェクトの設定**（歯車のアイコン）を開きます。
2. **スクリプト プロパティ** で、投稿先ごとに次のプロパティを追加します。

| プロパティ | 値 |
|---|---|
| `CHAT_WEBHOOK_投稿先の名前`（例：`CHAT_WEBHOOK_douga`） | スペースの Webhook の URL |

**投稿先の名前**（`CHAT_WEBHOOK_` の後ろの部分）は、PPM でこの投稿先を選ぶときの名前になります。

必要なら、次のプロパティも追加できます。

| プロパティ | 内容 |
|---|---|
| `CHAT_DISABLED` | `true` にすると、すべての Chat 通知を止めます（緊急時の停止用）。 |
| `CHAT_MAX_PER_MINUTE` | 1分あたりに送れる通知の数の上限です（既定は `60`）。 |

### 外部への接続を承認する

Chat への投稿には、外部のサービスへ接続する権限が必要です。

1. エディタの上部で、実行する関数に `authorize` を選び、**実行** を押します。
2. 権限の確認画面が表示されたら、承認します。

承認していないと、通知を送ったときに「UrlFetchApp.fetch を呼び出す権限がありません」という意味のエラーになります。

### デプロイする

スクリプトを、ウェブアプリとしてデプロイします。
手順は [Google スプレッドシート連携](google-spreadsheet.ja.md) の「Apps Script のウェブアプリをデプロイする」と同じです。
すでにデプロイしているスクリプトに Chat の設定を追加した場合は、**デプロイを管理** で **新バージョン** としてデプロイし直します。

## PPM に投稿先を登録する

1. **プロジェクト設定** の **基本情報** を開きます。
2. **Google Apps スクリプトのURL** に、ウェブアプリの URL を入れます（スプレッドシート連携で設定済みなら、そのままです）。
3. **Google Chat 投稿先** に、スクリプト プロパティに登録した投稿先の名前を、カンマかセミコロンで区切って入れます。
   **スクリプトから取得** を押すと、スクリプトに登録されている名前を読み込んで、まだ入っていないものを追加します。
4. **テストメッセージを送信** を押して、テストのメッセージが届くか確かめます。投稿先が複数あるときは、メニューで送り先を選びます。
5. **保存する** を押します。

**スクリプトから取得** を押したときに、PPM に入っている名前でスクリプトに登録されていないものがあれば、その名前も表示されます（その投稿先への通知は失敗します）。
投稿先の名前を1つだけ書き換えた場合は、その投稿先を使っているステップの設定も、新しい名前に書き換わります。

## アクションにステップを追加する

通知を送りたいアクションに、**Google Chatに通知を送る** のステップを追加します（[工程を設計する](../designing/workflows.ja.md) を参照）。

| 項目 | 内容 |
|---|---|
| **投稿先** | 基本情報で登録した投稿先から選びます。 |
| **メッセージ** | 送るメッセージです。空のときは、灰色で表示されている既定のメッセージ（プロジェクト、カット、日時、工程、アクション、ユーザー）を送ります。 |
| **自由記入欄を許可** | オンにすると、アクションの確認画面にメッセージを書き足す欄が表示されます。書いた内容は、メッセージの後ろに付けて送られます。 |
| **キャンセル時に通知する** | オンにすると、アクションを取り消したときに、取り消しの通知を送ります。 |
| **キャンセルメッセージ（任意）** | 取り消したときに送るメッセージです。空のときは、「【以下の操作がキャンセルされました】」の行に続けて、元のメッセージを送ります。 |
| **スレッドキー（任意）** | 同じスレッドキーのメッセージは、Google Chat で1つのスレッドにまとめられます。たとえば `[CUTNUMBER]` にすると、カットごとの通知と取り消しの通知が、同じスレッドに並びます。 |

メッセージ、キャンセルメッセージ、スレッドキーでは、次のマクロを使えます。

| マクロ | 置き換えられるもの |
|---|---|
| `[CUTNUMBER]`、`[SEQUENCE]`、`[EPISODE]` | カット番号、シークエンス、話数 |
| `[USER_NAME]` | 環境設定のユーザー名 |
| `[CURRENT_DATE]` | 実行した日付（`2026/10/30` の形） |
| `[CURRENT_DATETIME]` | 実行した日時 |
| `[PROJECT_NAME]` | 基本情報のプロジェクト名 |
| `[WORKFLOW_NAME]` | 工程の名称 |
| `[ACTION_NAME]` | アクション名 |

## 送ったときの動き

- アクションの確認画面に、送るメッセージが表示されます。
- 通知は、**OK** を押した後に、裏で送られます。続けて送る通知は、Google Chat の投稿数の上限を超えないよう、約1秒ずつ間を空けて送られます。
- 一時的なエラー（Google 側の混雑や、接続できなかった場合など）のときは、少し待って、3回まで送り直します。
- 送れなかったときは、警告が表示されます。
- 送り終わる前に PPM を終了しようとすると、確認のメッセージが表示されます（[メイン画面](../using/main-window.ja.md) を参照）。
- 次の場合、このステップは飛ばされます：**Google Apps スクリプトのURL** が空のとき、投稿先が基本情報に登録されていないとき。

送った記録は、ログフォルダの `google_chat/google_chat.log` に残ります（投稿先の名前、成功・失敗、失敗の理由）。
スクリプトの URL は、記録に残りません。
