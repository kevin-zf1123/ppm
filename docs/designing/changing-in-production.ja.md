# 運用中に設計を変えるときの注意

制作が始まった後でも、プロジェクトの設計は変えられます。
途中でチェックの工程を増やしたり、ファイル名の決まりを直したりすることは、よくあります。

PPM の進捗は、カットのファイルと、いくつかの記録のファイルで表されています（[進捗はファイルで管理される](../concepts/progress-files.ja.md) を参照）。
設計を変えたときに気を付けるのは、**すでにあるファイルや記録が、新しい設計に合わなくなること**です。
合わなくなったファイルは、手で直せば元どおりに使えます（[ファイルを直接扱う](../concepts/working-with-files.ja.md) を参照）。

プロジェクトを保存すると、すべての工程グループについて、カットのファイルを探し直して、工程ごとのカットの一覧が作り直されます（[プロジェクトの保存とテスト](saving-and-testing.ja.md) を参照）。
そのため、**キューファイルから判断できること**は、保存した時点で新しい設計に合わせて並び直します。

## 変えても問題ないもの

次の設定は、制作の途中で変えても、すでにある記録には影響しません。

- プロジェクト名、説明
- 工程の名称、接尾辞、表示色
- 工程グループのラベル名
- アクション名、アクションのステップ、次の工程（次にアクションを実行したときから使われます）
- カット情報のラベル、色、手動設定を可能にするかどうか
- 役割
- カットサムネイルのパス、XDTSファイル名、「開く」ボタンで探索するサブフォルダ
- Google Apps Script の URL、Google Chat の投稿先
- 工程の並び順

**工程の追加**も、そのまま行えます。
保存すると、新しい工程の条件パスに当てはまるファイルを持っているカットが、その工程に並びます。
途中の工程に追加した場合、すでに先の工程にいるカットはそのまま進みます。
今いるカットを新しい工程に乗せたいときは、キューファイルの名前を新しい条件パスに合わせて直します（[ファイルを直接扱う](../concepts/working-with-files.ja.md) の例を参照）。

## 注意が必要なもの

### 条件パス

条件パスを変えると、それまでの名前のファイルは、その工程の条件に当てはまらなくなります。
保存した後、カットがその工程に並ばなくなります。
カットを並べ直すには、すでにあるファイルの名前を新しい条件パスに合わせて直し、工程グループの更新ボタン（回転矢印のアイコン）を押します。

### 工程の削除

工程を削除すると、その工程にいたカットは、どの工程にも並ばなくなります。
カットのファイルは消えないので、別の工程の条件パスに合わせて名前を直せば、その工程に並びます。

削除した工程を同じ名前で作り直しても、工程の ID は新しくなります。
メイン画面で工程のチェックやロックの状態は ID で記録されているので、作り直した工程では、チェックとロックをやり直すことになります。

### 工程グループの ID名

工程グループの ID名は、工程グループの所属の記録（`progress/LO.ini` など）と、工程ごとのカットの一覧（`progress_cache/LO_details.ini` など）のファイル名に使われています。

ID名を変えると、それまでの所属の記録が見つからなくなり、その工程グループのカットが一覧に並ばなくなります。
どうしても変える場合は、プロジェクト情報フォルダの `progress/古いID名.ini` と `progress_cache/古いID名_details.ini` を、新しい ID名に合わせて名前を変えてください。
（「工程グループを移動」ステップの移動先は、ID名を変えても自動で付いていきます。）

### 工程グループの ID

工程グループの ID は、工程グループの並び順と、メイン画面の一覧表示で見出しを開いているかどうかの記録に使われます。
ID を書き換えると、その工程グループの工程や、「工程グループを移動」などのステップの指定先は、新しい ID に自動で付け替えられます。カットの記録にも影響はありません。
ただし、見出しを開いているかどうかの記録は、各自の PC で、その工程グループの分だけ元に戻ります。

### カット情報の ID名

カット情報は、カットごとのファイルに ID名で記録されています。
ID名を変えると、それまでに付けたカット情報が表示されなくなります。
カット情報のファイル（`scene_info` フォルダの `c0001.ini` など）の中の名前を、手で書き換えれば元に戻ります。

`REWIND` と `BANK` は、PPM の機能が使う名前なので、変えないでください（[カット情報](info-tags.ja.md) を参照）。

### カット番号の接頭辞

接頭辞は、カット情報のファイル（`c0001.ini`）とログのファイル（`c0001.md`）の名前にも使われています。
変えると、それまでのカット情報（テイクの記録を含む）とログが見つからなくなります。
変える場合は、これらのファイルの名前も変えてください。

### 100カットごとにまとめる [SEQUENCE]

オン・オフを変えると、カット情報とログを探すフォルダの構成が変わります（シークエンスごとのフォルダを使うかどうか）。
PPM は、すでにあるフォルダを並べ替えません。
それまでのカット情報（テイクの記録を含む）とログが見つからなくなり、`[TAKE]` や `[R_TAKE]` が違うフォルダを指すことがあります。

制作の途中では変えないことをおすすめします。
変える場合は、ログフォルダと、プロジェクト情報フォルダの `scene_info` フォルダの中のファイルを、新しい構成に合わせて手で移してください。
パスの中の `[SEQUENCE]` も、必要に応じて書き換えます。

### フォルダの場所

ルートフォルダ、進捗情報用フォルダ、履歴のルートフォルダ、パスマクロのパスを変えたときは、PPM はファイルを移しません。
新しい場所に、それまでのファイルを移してから保存してください。
共有フォルダのサーバーを移す場合などの手順は、[共有フォルダでの運用](../administration/shared-operation.ja.md) を参照してください。

### 話数

「話数あり」をオンにすると、進捗情報用フォルダと履歴のルートフォルダの中に、話数ごとのフォルダが使われるようになります。
それまでの記録は、話数のフォルダの外にあるので、見つからなくなります。
話数のある作品は、制作を始める前に「話数あり」にしておいてください。
話数の名前を後から追加するのは、問題ありません。
